## Contexte

Chaque restaurant affiche « Minimum X € » (Burger Factory : 20,00 €).

## Préconditions

Alice connectée (ou clé API) ; Burger Factory.

## Étapes pour reproduire

1. Ajouter 1 × Frites maison (3,50 €) au panier.
2. Ouvrir /checkout, choisir Carte bancaire et confirmer.

## Résultat attendu

La commande est refusée : « Minimum de commande de 20,00 € non atteint ».

## Résultat obtenu

Commande confirmée avec 3,50 € de sous-total (6,49 € livraison incluse). Même résultat via l'API.

## Preuves

**Reproduction API (commande de rejeu)**

```bash
curl -s -X POST -H 'X-API-Key: quickorder-demo-key' -H 'Content-Type: application/json' \
  -d '{"items":[{"product_id":3,"quantity":1}],"payment_method":"card"}' http://127.0.0.1:5000/api/orders
```

## Analyse

- **Cause probable** : `restaurant.minimum_order` n'est jamais lu dans app/routes/orders.py ni app/routes/api.py.
- **Impact** : Livraisons non rentables pour le restaurant ; règle affichée mais trompeuse.

## Suggestion de correction

Comparer le sous-total (avant remise) au minimum au checkout et à l'API (400/409 avec le montant manquant) ; afficher le manque dans le panier.
